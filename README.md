# PDF_Classification_Project1
ML Lab - Invoice / Bill / Receipt Classification

## How to Run
pip install streamlit pytesseract PyMuPDF pillow scikit-learn
python -m streamlit run app.py

## Files
- prepare_invoice_data.py / prepare_receipt_data.py - prepare dataset
- test_bill3_ocr.py / test_invoice_ocr.py - OCR testing (bill3.png)
- train_model.py - TF-IDF classifier
- scanned_test.pdf - test file
- receipt_data.csv - extracted data
